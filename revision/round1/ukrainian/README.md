# Український переклад доопрацьованих матеріалів IJF

Два незалежні документи для наукового обговорення між співавторами. Пакет
містить усі потрібні файли LaTeX, бібліографію, стиль BibTeX і чотири
векторні рисунки. Папка пакета може бути поза репозиторієм.

## Збирання

Потрібні PowerShell, XeLaTeX та BibTeX з актуального TeX Live або MiKTeX,
українські шаблони переносу для XeLaTeX, шрифти DejaVu Serif та DejaVu Sans.
У дистрибутиві TeX мають бути встановлені стандартні пакети AMS, mathtools,
polyglossia, fontspec, natbib, authblk, booktabs, caption, enumitem, framed,
graphicx, geometry, needspace та hyperref. У TeX Live достатньо схеми Full і шрифтів
DejaVu, встановлених через систему.

У PowerShell з папки перекладу виконайте

```powershell
.\Build-Ukrainian-Translation.ps1
```

Параметр `-OutputDirectory` задає іншу папку для результатів. За
замовчуванням `build` поруч зі сценарієм міститиме обидва PDF та журнали
остаточних проходів. Сценарій виводить SHA-256 зібраних PDF. Для окремого
збирання рукопису потрібні XeLaTeX, BibTeX і ще три проходи XeLaTeX. Для
відповідей достатньо двох проходів XeLaTeX.

`TRANSLATION_COVERAGE.csv` містить початкові й кінцеві номери рядків
англійських фрагментів. У відповідних файлах LaTeX ці фрагменти позначено
коментарями `% M…` і `% R…`. Блоки формул у реєстрі мають окремі позначки.
